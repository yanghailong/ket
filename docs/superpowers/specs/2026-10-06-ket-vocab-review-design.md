# KET 词汇找回 · 设计文档

日期：2026-10-06
状态：待审阅

## 1. 背景与目标

- **使用者**：11 岁五年级孩子，备考剑桥 A2 Key for Schools（KET）。
- **现状**：孩子以前学过约 1500 个 KET 词汇，现在有部分遗忘。
- **目标**：做一个本地 HTML 学习页面，**先筛出遗忘的词，再用记忆曲线集中复习**，并配合每日打卡和星星激励，让孩子坚持每天约 15 分钟。
- **成功标准**：
  - 孩子双击打开就能用，不需要联网或登录。
  - 约一个月内筛完 1500 词（默认每天 50 个）。
  - 家长能看到筛查进度、遗忘数、已捡回数和打卡记录。

### 不做的事（YAGNI）

- 不做语法、阅读、听力、写作、口语模块（以后可以另立项目）。
- 不做云端同步、多设备、远程查看（以后需要再升级）。
- 不做"导入自定义词表"。
- 不做星星兑换商城（兑换规则由家长在现实里定）。

## 2. 技术方案

- **单个 HTML 文件**：纯 HTML、CSS 和原生 JavaScript，所有代码和词库都写在一个文件里，没有任何外部依赖，断网也能用。
- 文件大约 300–400KB。
- 进度存在浏览器的 `localStorage` 里。
- 发音用浏览器自带的 `speechSynthesis`（Web Speech API）。

### 源码组织

开发时把代码按职责拆成几个文件，最后用构建脚本合并成一个 HTML 交付：

| 单元 | 职责 | 依赖 |
|---|---|---|
| `words` 词库数据 | 约 1500 词的数组 | 无 |
| `srs` 排期逻辑 | 状态转换、计算下次复习日期（纯函数） | 无 |
| `daily` 每日任务 | 根据进度和日期生成当天任务（纯函数） | srs |
| `storage` 存储 | 读写 localStorage，导出和导入 JSON | 无 |
| `speech` 发音 | 封装 speechSynthesis，选择语音 | 无 |
| `ui` 界面 | 各个视图的渲染和交互 | 以上全部 |

- `srs` 和 `daily` 都是纯函数，"今天的日期"作为参数传进去，方便测试时模拟跳过若干天。
- 测试用 Node 自带的测试框架（`node --test`），不需要额外安装依赖。

## 3. 页面结构

整个应用只有一个页面，通过顶部或底部导航在 5 个视图之间切换。

### 3.1 🏠 首页（今日任务）
- 顶部显示：连续打卡天数 🔥、星星总数 ⭐。
- 两张任务卡：「① 复习遗忘词 N 个」和「② 筛查新词 M 个」，完成后打勾。
- 总进度条：1500 词中已掌握、遗忘、已捡回、未筛查各有多少。

### 3.2 🔍 筛查
- 每题显示一个英文单词和 4 个中文选项，带 🔊 发音按钮和倒计时（默认 8 秒）。
- 答完立刻显示对错。答错时会显示正确答案，停留约 1.5 秒后自动进入下一题。

### 3.3 🔁 复习
每个词分两步：
1. **单词卡**：显示英文、音标、词性、中文、例句和例句翻译，并自动朗读一遍。孩子看完点"我记住了"。
2. **拼写题**：显示中文，可以点 🔊 听发音，然后输入英文。

判定规则：
- 拼对算本轮通过。
- 拼错会显示正确拼写，这个词算本轮失败。
- 拼写判定时不区分大小写，也会忽略首尾空格。

家长关闭拼写后，第 2 步改成"听发音四选一（选英文单词）"。

### 3.4 📒 词本
- 可以按话题或按状态筛选，支持搜索英文或中文。
- 点击单词可以查看完整信息并听发音。

### 3.5 👨‍👩‍👧 家长
- **设置**：
  - 每日筛查数量：30、50（默认）、100。
  - 倒计时：5、8（默认）、12 秒，或关闭。
  - 拼写：开（默认）或关。
- **统计**：最近 14 天的打卡日历、每天的筛查正确率和复习正确率。
- **备份**：导出进度（下载 `.json` 文件）、导入进度。
- **重置**：清空全部进度，需要二次确认（输入"重置"两个字）。

## 4. 单词状态与排期规则

### 4.1 状态

| 状态 | 什么时候进入 | 之后怎么处理 |
|---|---|---|
| `new` 未筛查 | 初始状态 | 等待进入筛查 |
| `known` 已掌握 | 筛查时答对 | 30 天后抽查一次 |
| `forgotten` 遗忘 | 筛查答错或超时；抽查失败 | 进入复习，从第 0 级开始 |
| `recovered` 已捡回 | 复习中连续通过 3 轮 | 30 天后抽查一次 |

### 4.2 复习间隔

（2026-10-06 修订：原先写的 1、2、4、7、15 天和"连续 3 次捡回"互相矛盾，经家长确认改为下面的规则。）

- 遗忘词记录连续通过次数 `streak`（0–2）。复习间隔表 `INTERVALS = [1, 2, 4]` 天。
- 遗忘词第一次被标记（筛查答错或抽查失败）时，`streak = 0`，下次复习日期 = 今天 + 1 天。
- 每轮复习**通过**：
  - `streak` 加 1。
  - 如果 `streak` 达到 3，状态变成 `recovered`，`streak` 归零，下次抽查日期 = 今天 + 30 天。
  - 如果还没到 3，下次复习日期 = 今天 + `INTERVALS[streak]`。
  - 按时复习的话，复习日是标记后的第 1、3、7 天。
- 每轮复习**失败**：`streak` 归零，下次复习日期 = 明天。

### 4.3 抽查

- `known` 和 `recovered` 状态的词，到期后会出现在复习任务里，题型和筛查一样，是四选一（选中文）。
- 抽查**答对**：状态保持不变，下次抽查日期 = 今天 + 30 天。
- 抽查**答错**：状态变成 `forgotten`，`streak` 归零，下次复习日期 = 明天。

## 5. 每日任务生成

每天第一次打开页面时，生成当天任务并保存下来。当天再打开，继续用这份任务。

- **复习任务**：所有已经到期的遗忘词和抽查词，按到期日期从早到晚排序，**最多取 40 个**。没取到的顺延，第二天继续排在前面。
- **筛查任务**：
  - 按话题顺序，从未筛查的词里取 N 个（N 是家长设置的数量）。
  - 如果未筛查的词不足 N 个，就把剩下的全部取出。
  - 如果已经没有未筛查的词，就不出筛查任务。
- **今天新标记的遗忘词**，要从第二天开始复习，不会加进当天的复习任务里。
- **答题保存**：每答一题就立即保存。中途退出后再打开，会从下一个没做的题接着做。

### 5.1 干扰项生成

筛查和抽查四选一中的 3 个错误选项，按下面的优先级挑选：
1. 同一话题、同一词性。
2. 同一词性。
3. 其他任意词。

另外还有两条限制：
- 中文释义和正确答案相同的词不能当干扰项。
- 4 个选项的位置随机打乱。

## 6. 打卡与星星

- **打卡**：当天的任务全部完成，就算当天打卡。
  - 如果当天某一项任务数量是 0（比如已经没有未筛查的词），这一项直接视为完成。
- **连续天数**：今天打卡时，如果昨天也打了卡，连续天数加 1；否则重置为 1。
  - 页面显示时，如果昨天和今天都没打卡，连续天数显示为 0。
- **星星规则**：
  - 每完成一项任务得 5 ⭐，两项都完成再加 5 ⭐。
  - 连续打卡天数第一次达到 7 天得 20 ⭐，第一次达到 30 天得 100 ⭐。之后每次达到 7 或 30 的整数倍时，也会再发一次。
- **星星只增不减**：断签不会扣星星。
- **完成庆祝**：当天两项任务都完成时，弹出庆祝画面，显示本次获得的星星和当前连续天数。

## 7. 词库

### 7.1 每个词的字段

```js
{
  id: "apple",        // 唯一 ID，直接用英文单词（词库增删时进度不会错位）
  en: "apple",        // 英文
  ipa: "/ˈæp.əl/",    // 音标（英式）
  pos: "n.",          // 词性：n. / v. / adj. / adv. / prep. / pron. / conj. / det. / num. / excl. / phr.
  zh: "苹果",          // 中文释义（简短，1–2 个意思）
  topic: "food",      // 话题 key
  ex: "I eat an apple every day.",  // 例句（A2 难度）
  exZh: "我每天吃一个苹果。"           // 例句翻译
}
```

### 7.2 来源与话题

- **来源**：参考剑桥 A2 Key for Schools 官方词汇表（Vocabulary List），共约 1500 词。
  - 中文释义、音标和例句由 Claude 编写。
  - 家长需要抽查其中几个话题，确认质量。
- **话题**：约 20 个，例如：
  - 家庭与朋友、学校与学习、食物与饮料、房屋与家居、衣服、身体与健康
  - 运动、爱好与休闲、旅行与交通、地点与建筑、天气、动物、自然
  - 购物、工作与职业、科技与通讯、时间与日期、数字与数量、情感与性格
  - 功能词（介词、代词、连词等）

### 7.3 自动校验（构建时执行）

- 没有重复的 `en` 和 `id`。
- 所有字段都不为空，`pos` 和 `topic` 的取值都在允许的列表里。
- 总词数在 1400–1600 之间（词库全部写完后由单元测试强制检查；分批编写词库期间，构建时只提示不报错）。

## 8. 发音

- 使用 `speechSynthesis`，按这个顺序选择语音：
  1. 优先 `en-GB`（英式）。
  2. 其次任意 `en-*` 英语语音。
  3. 都没有时，🔊 按钮显示为不可用，并提示"本设备不支持发音"。
- 有的浏览器语音列表是异步加载的，需要监听 `voiceschanged` 事件。
- 语速设为 0.9。
- **音效**：答对的"叮"和答错的提示音，用 Web Audio API 现场合成短音，不需要额外的音频文件。

## 9. 界面风格

- 浅色背景、大圆角卡片、明亮但柔和的主色。
- 单词字号约 40px，按钮最小点击区域 48px。
- **动效**：答对时卡片变绿，答错时卡片轻微抖动并显示正确答案，完成任务时显示庆祝动画。
- **响应式布局**：
  - 适配平板和电脑屏幕，最小支持 360px 宽。
  - 宽屏时内容居中，最大宽度约 720px。

## 10. 存储与容错

### 10.1 存储内容

存储键名：`ketVocab.v1`。数据结构如下：

```js
{
  version: 1,
  settings: { dailyScreen: 50, timerSec: 8, spelling: true },
  words: { [id]: { status, streak, due /* YYYY-MM-DD */, lastSeen } },
  today: { date, reviewIds: [], screenIds: [], reviewDone: [], screenDone: [] },
  stats: { stars, streakDays, lastCheckin, history: { [date]: { screenRight, screenTotal, reviewRight, reviewTotal, checked } } }
}
```

- `words` 里只保存状态不是 `new` 的词，所以存储量不会太大。
- **日期**：统一用这台设备的本地日期，格式是 `YYYY-MM-DD`。

### 10.2 容错

- **localStorage 不可用**（比如无痕模式或权限被禁止）：顶部显示黄色提示"进度无法保存"，进度只保存在内存里，仍然可以正常练习。
- **数据损坏或版本不认识**：先把原始数据备份到 `ketVocab.v1.broken`，再用初始状态启动，并提示家长。
- **导入备份**：先检查 `version` 和字段结构，不合法就拒绝导入，当前进度保持不变。
- **重置进度**：需要输入"重置"二字确认。

## 11. 测试与验证

### 11.1 单元测试（`node --test`）
- **srs**：
  - 测试各种状态转换。
  - 检查复习间隔是否按 1、2、4 天推进。
  - 检查连续通过 3 轮后变成"已捡回"。
  - 检查失败后归零。
  - 检查抽查失败后回到"遗忘"。
- **daily**：
  - 检查复习上限 40 个和顺延。
  - 检查按话题顺序取筛查词。
  - 检查未筛查词不足或为空时的处理。
  - 检查跨天时会重新生成任务。
- **打卡与星星**：
  - 检查连续天数的累加和重置。
  - 检查 7 天和 30 天奖励。
  - 检查某项任务数量为 0 时视为完成。
- **干扰项**：
  - 检查不含正确答案，也不含同义的中文。
  - 检查数量正好是 3 个。
- **词库校验**：同第 7.3 节。

### 11.2 手动验证
- 在浏览器中走一遍完整流程：首页 → 筛查 → 复习 → 打卡庆祝 → 家长页导出 → 重置 → 导入恢复。
- 在 Safari 和 Chrome 上都检查一次发音。

## 12. 交付物

- `dist/ket-vocab.html`：最终交付给孩子用的单个文件。
- `src/`：源码，按第 2 节的单元拆分。
- `tests/`：单元测试。
- `build.mjs`：构建脚本，负责校验词库并把源码合并成单个 HTML。
